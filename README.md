# Oluseun Adeboyejo Foundation

A responsive, editorial-style website presenting the foundation’s education and community work through its real outreach photography.

## Highlights

- Distinct visual identity based on the existing logo
- Real foundation photography and an evidence-led featured initiative
- Clear programme and partnership pathways
- Honest scholarship preparation guide without a misleading form
- Accessible mobile navigation and reduced-motion support
- Lightweight HTML, CSS and JavaScript with no framework dependency

Open `index.html` in a browser or serve the folder with any static web server.
